## Stage 2: Дизайнер & Автор текстів — ГОТОВО ДО ПРОВЕДЕННЯ

### Що вже зроблено:
- ✓ `/docs/design.md` — повна дизайн-система (701 рядок)
  - Токени дизайну (світла/темна тема, кольори, шрифти)
  - Компоненти & стани (кнопки, поля, діалоги, кільце)
  - Карта 11 екранів & схеми (ASCII wireframes)
  - Правила доступності WCAG 2.2 AA
  - 23 priority завдання для dev (P0–P4)
  - Чек-лист перед запуском

### Що потребує завершення:

#### 1. `/docs/content-guide.md` (ще не створено)
Повинен містити:
- Тон & голос (нейтральний, без порад)
- Словари для кожного реґіону
- Шаблони помилок & порожніх станів
- Правила множини & граматики

#### 2. `/i18n/uk.json` (ще не створено)
Базовий словник для української мови з ключами для:
- Назв розділів за замовчуванням (готівка, депозит, ФОП, крипта, облігації)
- Назв цілей (подушка безпеки, первий дім, відпустка, авто)
- Назв боргів (іпотека, кредит на авто, кредитна карта)
- Повідомлень (помилок, порожніх станів, натяків)
- Частоти зарплати (щомісячно, раз на два тижні, щотижня)

#### 3. `/i18n/en.json` (ще не створено)
Англійський переклад вищевказаних ключів

#### 4. Інші мови (для майбутніх версій)
- `i18n/fr.json` — французька
- `i18n/de.json` — німецька
- `i18n/pl.json` — польська
- `i18n/es.json` — іспанська
- `i18n/it.json` — італійська

### Критерії готовності Stage 2:
- [ ] Контент-гайд написаний & переглянутий
- [ ] i18n/uk.json заповнений для базових ключів (мінімум 50 ключів)
- [ ] i18n/en.json тісто переглянутий носієм англійської
- [ ] Усі ключи у дизайні замінені текстовими const
- [ ] Помилки мають іконку + текст + aria-live

**Кроки для людини перед початком Stage 2:**
1. Переглянути дизайн.md і конкретизувати нейтральний тон (приклади для 5 різних помилок)
2. Визначити критичні 50 ключів i18n (найчастіше використовувані)
3. Переглянути з носієм англійської один раз перед Stage 3

## Stage 3: Розробник (ОЧІКУЄ ПІДТВЕРДЖЕННЯ)

### План розробки (з spec.md):
1. Схема даних & міграція старих копій ( 1–2 дні)
2. Профілі країн JSON & вибір країни при першому запуску (1–2 дні)
3. Переклади (i18n) — заміна hardcode текстів (1 день)
4. Частота зарплати — вибір за профілем (1 день)
5. Живі курси валют з запасним варіантом (2 дні)
6. Оновлений дизайн — bottom sheet, кнопка назад, іконки помилок (3–4 дні)
7. PWA & нотифікації для оновлень (1–2 дні)
8. GitHub Actions & GitHub Pages (1 день)

### Залежності перед початком Stage 3:
- Stage 2 має бути завершена (content-guide.md + i18n файли)
- JSON profіли конвертовані з markdown (util: kan автоматизувати)
- Затвердження всіх API запитів користувачем

## Важливо

- **Дані користувача:** localStorage, ключ `money-mini-v1`, міграція обов'язкова
