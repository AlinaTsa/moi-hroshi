## 3. Карта екранів

### Основні екрани (390x844 або 375x667)

```
1. ОНБОРДИНГ (три кроки)
   → Вибір країни (до профілю)
   → Основна валюта й локаль
   → Розділи, які потрібні

2. ГОЛОВНИЙ ЕКРАН ("Гроші")
   - Заголовок + кнопка приховання сум
   - Вкладки (Гроші | План)
   - Якщо зарплата чекає: prompt для підтвердження
   - Кільце накопичень
   - Вкладки цілей + блок цілі
   - Легенда (розбір за розділами)
   - Динаміка (графік)
   - По валютах (таблиця)
   - Терміни (депозити до дати)
   - Розділи (кожен розділ = картка з записами й кнопка +)
   - Деталі (курси, резервна копія, налаштування) в <details>

3. ПЛАН (tab Plan)
   - Зарплата
   - Куди йде зарплата (flow bar)
   - Прогноз на рік
   - Цілі й скільки відкладати
   - Кредити й іпотека

4. ДІАЛОГ СУМИ (modal)
   - Назва (опціонально)
   - Сума (inputmode decimal)
   - Валюта (чіпи QUICK, або власна)
   - Якщо g.term: ставка & дата до
   - Видалити | Скасувати | Зберегти

5. ДІАЛОГ ЦІЛІ (modal)
   - На що збираєте
   - Скільки потрібно
   - Валюта цілі
   - Бажана дата
   - Скільки щомісяця (опціонально)
   - Рахувати з розділів
   - Видалити ціль | Скасувати | Зберегти

6. ДІАЛОГ ЗАРПЛАТИ (modal)
   - Скільки щомісяця
   - Валюта
   - Число місяця
   - Куди зараховувати (select: розділ)
   - До якого запису додавати (select: сума в розділі)

7. ДІАЛОГ КРЕДИТУ (modal)
   - Назва (іпотека, кредит на авто)
   - Залишок боргу
   - Валюта
   - Платіж щомісяця
   - Ставка % річних (опціонально)
   - Остання виплата

8. ДІАЛОГ ВИТРАТ (modal)
   - Сума на місяць
   - Валюта

9. ПОРОЖНІЙ СТАН (money tab)
   - Заголовок: «Починайте звідси»
   - Кнопка: Розглянути демо | Додати першу суму

10. ПОРОЖНІЙ СТАН (план tab)
    - «План з'явиться...»
    - Кнопка: Додати зарплату

11. ПОМИЛКА (валідація, курс відсутній)
    - Текст помилки під полем ( 14px, --bad)
    - Не лякай: «курс не вказано» замо «ПОМИЛКА!»
```

## 5. Правила доступності

### WCAG 2.2, рівень AA (наша планка вища)

**Контраст:**
- Звичайний текст на фоні: ≥ 4.5:1
- Великий текст (18px+): ≥ 3:1
- Активні елементи інтерфейсу (чіпи, кнопки): ≥ 3:1
- Перевірено в обох темах

**Мобільне:**
- Цілі для дотику: мінімум 44×44 px
- Відстань між цілями: мінімум 8 px
- Клавіатура не закриває поля введення (auto-scroll при focus)

**Видимість & навігація:**
- Видимий фокус (outline або ring), не перекривається вмістом
- Повна навігація Tab / Shift+Tab
- Режим «встановленого додатка»: власна кнопка «Назад»

**Екранні читачі (VoiceOver, TalkBack):**
- `<label>` для кожного поля (атрибут `for`)
- `aria-label` для іконок без тексту (кнопка приховання, кільце)
- `role="group"` + `aria-label` для segment controls
- `aria-pressed="true|false"` для вибір-кнопок
- `aria-live="polite"` на числа в центрі кільця (оновлюються динамічно)
- Помилки в `aria-live` регіонах (статус оголошується)

**Масштабування & адаптивність:**
- Текст до 200% без горизонтальної прокрутки
- Мінімальна ширина: 320 px (no shrink)
- `viewport-fit=cover` для safe areas (виріз, домашна смужка)
- `env(safe-area-inset-*)` на padding

**Анімація & рух:**
- `prefers-reduced-motion: reduce` → без анімацій
- Поточно: кільце анімується, потрібна перевірка (може змінитись на instant при reduce)

**Мова & простота:**
- `lang="uk"` на документі
- Тексти простою мовою: немає жаргону
- Граматика: множина в залежності від числа (тести виконані пропозиції)

## 7. Список правок для dev (з пріоритетами)

### P0 — Мобіль, доступність, коректність

1. **Bottom sheet замість dialog** — мобіль першим. Діалоги мають з'являтись знизу екрана, а не по центру. Потрібен wrapper, що прилипає до низу з безпечними зонами.
   
2. **Кнопка назад у встановленому додатку** — коли додаток встановлено на головний екран, немає адресного рядка. Потрібна видима кнопка назад вверху ліворуч.

3. **Іконка помилки + текст** — помилки (курс не вказано, поле порожнє) не мають бути лише по кольору. Додати `⚠️` чи іконку помилки, текст у aria-live.

4. **Видалення: Скасувати замо Ви впевнені?** — після видалення показати inline `✓ Видалено. [Скасувати]` на 3 сек., а не модаль.

5. **Safe area insets** — padding-bottom уже є, але потрібна перевірка на iPhone з notch & home indicator.

6. **Label для всіх полів** — помічено, що деякі поля (например, в чіпах) не мають `<label for="">`. Додати атрибут `aria-label` на svg circle в кільці.

### P1 — UX & зручність

7. **Запам'ятовування останньої валюти** — коли користувач вводить суму в USD, наступне додавання повинно пропонувати USD, не UAH.

8. **Запам'ятовування останнього розділу** — + Додати суму → розділ → + Додати суму (знову) повинен пропонувати той же розділ.

9. **Шаблони цілей** — чіпи для популярних цілей (Подушка, Відпустка, Розумні покупки) з типовими сумами за країною. Мета: скоротити до 2 дотиків замо 5.

10. **Шаблони боргів** — чіпи (Іпотека, Кредит на авто, Кредитна карта) з типовими ставками.

11. **Курси на головній сторінці** — курс не повинен бути в деталях. Повинен бути на видному місці, або швидкий доступ (нижня смужка, жест).

12. **Ранг ціллей** — активна ціль повинна мати ясну позицію (перша вкладка, яскравіша, або обведена).

### P2 — Полірування й довіра

13. **Режим приватності одним дотиком** — кнопка приховання сум присутня, але невідомо, чи переноситься налаштування між сеансами. Потрібен локальний кеш (`localStorage`).

14. **Індикатор офлайну & синхронізації** — якщо вихід в Інтернет для курсів, показати статус: `📡 Оновлено сьогодні | ⚠️ Офлайн, остання дата...`

15. **Підказка встановити на головний екран** — один раз, без нав'язливості (не кожен запуск).

16. **Великий шрифт (системний 200%)** — перевірити, що текст не ламується, вводити фокус не закривається.

17. **Довгі числа (1 234 567 890,12)** — використовуються табличні цифри, але потрібна перевірка, що дуже довгі числа не обрізаються.

18. **Долгі назви розділів** — імена на 30 символів (у видох країнах можуть бути довше). Перевірити перенесення, не калічення іконки.

### P3 — Функціонал за країнами

19. **Профілі країн** — місця в схемах для `{country}.json` з типовими розділами, цілями, частотою зарплати. (ANALYST_BRIEF структурує це, дизайн має місця для заповнення.)

20. **День зарплати: день місяця від 1 до 31** — обробка останнього дня місяця (30 чи 31, залежно від місяця). Поле повинно мати приклад `1–31` або календар-піккер.

### P4 — Деталі ергономіки

21. **Чіпи на темній темі** — перевірити контраст чіпів у темній темі, особливо неактивних.

22. **Фокус в діалозі** — при відкритті діалогу, фокус повинен перейти на перше поле (виконується, потрібна перевірка з читачем екрана).

23. **Залишок в пальці великого пальця** — основні кнопки (+, Додати) повинні бути досяжні однією рукою на екрані 390×844.

## 10. Примітки для розробника

1. **Кільце** — побудоване на SVG, анімується через stroke-dasharray. Визначте, чи нормально працює на Сафарі (iOS).

2. **Чіпи валют** — список QUICK = [UAH, USD, EUR, USDT, BTC]. FIAT3 = [UAH, USD, EUR]. Можливо розширити для де-DE, fr-FR, ...

3. **Таблиці** — лічильники, графіки лініші просто побудовані на SVG з числами. Потрібна перевірка з NVDA/VoiceOver.

4. **LocalStorage** — ключ `money-mini-v1`, миграція в `migrate()`. Не змінюйте ключ без міграції.

5. **Резервна копія** — текстова (JSON в textarea). Для серйозного експорту потрібна опція скачування файлу.

6. **Ставки & дати** — циклічні розрахунки. Переконайтесь, що дневи до дати = точні (365 днів = 1 рік, але місяці різні).
