# Завдання для Kiro Crew (скопіюйте цей текст у головну розмову з агентом `lead`)

Ти агент `lead` проєкту «Мої гроші» (папка проєкту відкрита). Прочитай `README.md`, `.kiro/steering/product.md`, `docs/ROLES.md`, `docs/ANALYST_BRIEF.md` і поточний `index.html`.

## Мета
Перетворити особистий додаток обліку грошей на міжнародний: Україна, Канада, США, Європа, Австралія. У кожного регіону свої типи рахунків, банки, частота зарплати, цілі й пріоритети. Вигляд сучасний і дуже зручний на телефоні, доступний, тексти спокійні й без порад, курси валют оновлюються самі (із запасним варіантом), додаток публікується на GitHub Pages. Дані користувачів не залишають пристрій.

## Етапи (по черзі, з зупинкою на підтвердження)
1. **Аналітик** (`analyst`): профілі країн у `docs/profiles/`, `docs/spec.md`, `docs/golden-cases.md`, `docs/open-questions.md`. Усе з джерелами й датами; що не перевірено, позначити. Покажи мені стислий підсумок і чекай «так».
2. **Дизайнер** (`designer`) і **автор текстів** (`writer`): `docs/design.md` зі схемами екранів, `docs/content-guide.md` і словники `i18n/uk.json`, `i18n/en.json`. Підсумок і чекай «так».
3. **Dev** (`dev`): невеликими кроками з комітами. Порядок: схема даних і міграція → профілі й вибір країни → переклади → частота зарплати → живі курси з запасним варіантом → оновлений дизайн → PWA й оновлення → GitHub Actions і GitHub Pages. Перед першим зверненням до будь-якого зовнішнього API запитай мене.
4. **QA** (`qa`) і **безпека** (`security`): тести й звіти. Якщо хоч один `VERDICT: NEEDS_CHANGES`, віддай dev на виправлення (до трьох кіл).
5. **Фінальна вичитка текстів** (`writer`).
6. **Реліз**: підготуй усе, але `git push` і публікацію роби лише після мого прямого «так».

## Правила
- Працюй по черзі, економ кредити.
- Особисті дані та реальні суми не потрапляють у файли, тести, скриншоти й коміти.
- Не ламай збережені дані користувачів: ключ `money-mini-v1` і міграції.
- Після кожного етапу оновлюй `docs/STATUS.md` і пиши мені українською до 10 рядків. У `docs/STATUS.md` веди окремий список «кроки для людини».
- Якщо щось неясно, став одне запитання, а не десять.

Починай з етапу 1.
