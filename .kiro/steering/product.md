# Проєкт «Мої гроші»: правила для всіх агентів

## Що це
Особистий додаток для обліку грошей: готівка в різних валютах, депозити, рахунки ФОП/бізнесу, крипта, облігації, цілі накопичення, зарплата, кредити та іпотека, прогноз на рік.
Працює як PWA (встановлюється на телефон), без акаунтів і без сервера для особистих даних.

## Незмінні принципи
1. **Дані користувача лишаються на його пристрої** (localStorage). Жодних реальних сум, імен чи резервних копій у репозиторії, у логах, у тестових даних, у скриншотах. Для тестів тільки вигадані дані.
2. **Нічого не ламаємо для існуючих даних.** Ключ сховища `money-mini-v1` і функція `migrate()` мають залишатися сумісними. Кожна зміна структури даних = нова міграція + тест.
3. **Працює без інтернету.** Живі курси лише покращення: якщо їх не вдалося отримати, додаток користується останніми збереженими або ручними курсами і чесно про це каже.
4. **Це не фінансова, не податкова і не інвестиційна порада.** Додаток рахує й показує. Будь-яка порада в тексті формулюється нейтрально («за вашими цифрами…»), без «купіть/продайте».
5. **Кожен факт про правила країни має джерело** (офіційний сайт держави, регулятора чи центробанку) і дату перевірки. Без джерела = позначка «НЕ ПЕРЕВІРЕНО» і в додаток не потрапляє.
6. **Країни = дані, а не код.** Логіка країни живе в профілях (`profiles/*.json`), а не в `if (country === ...)` по всьому коду.
7. **Мова за замовчуванням: українська.** Додаткові мови додаються через словники, а не заміною рядків у коді.

## Мова спілкування
Агенти пишуть користувачці українською, просто, без жаргону. Код, назви файлів і коміти англійською.

## Економія кредитів Kiro
- Працюємо по черзі, не паралельно, якщо завдання залежать одне від одного.
- Перед великою зміною коротко кажемо, що саме збираємося робити, і чекаємо «так».
- Не запускаємо повні перевірки після кожного дрібного правлення. Один раз перед здачею етапу.

## Що потребує окремого підтвердження користувачки
`git push`, встановлення нових залежностей, звернення до зовнішніх API, видалення файлів, зміна структури даних.

## Критерії готовності (Definition of Done) для будь-якого етапу
- Розрахунки мають контрольні приклади й тести; незалежний перерахунок збігається.
- Існуючі дані користувача не втрачаються (тест міграції зі старих копій).
- Працює без інтернету; відсутність курсів чи API не ламає додаток.
- Немає порушень доступності серйозного рівня; обидві теми перевірено; цілі дотику ≥ 44 px.
- Усі тексти з словників, без порад, множина правильна.
- Жодних особистих даних чи секретів у репозиторії; мережеві запити не містять сум.
- `docs/STATUS.md` оновлено; зміни зафіксовано в `CHANGELOG.md`.

## Кроки, які агенти не замінять (потрібна людина)
Перевірка на реальних людях із різних країн · консультація місцевого бухгалтера чи фінансового консультанта щодо податкових фактів · юридична перевірка застережень і політики приватності · перевірка перекладів носіями мов · ручний тест зі зчитувачем екрана на справжньому телефоні.
