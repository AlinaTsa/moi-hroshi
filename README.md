# Мої гроші

Особистий додаток для обліку грошей: готівка в різних валютах, депозит, ФОП, крипта, облігації, цілі, зарплата, кредити й іпотека, прогноз на рік. Працює в браузері, встановлюється на телефон як звичайний додаток, **дані зберігаються лише на вашому пристрої**.

## Що в папці
```
index.html                 сам додаток (поки що один файл)
manifest.webmanifest       щоб додаток можна було встановити на телефон
sw.js                      робота без інтернету
icons/                     іконки
.kiro/agents/              ролі: lead, analyst, designer, writer, dev, qa, security
.kiro/steering/product.md  спільні правила для всіх ролей
docs/ROLES.md              що робить кожна роль і чому саме ці
docs/ANALYST_BRIEF.md      стартовий бриф про логіку країн
docs/TASK.md               готове завдання для Kiro Crew
tests/                     сюди qa складатиме тести
```

## Швидка перевірка на комп'ютері
У Терміналі, у папці проєкту:
```
python3 -m http.server 8080
```
і відкрийте http://localhost:8080 у браузері. Зупинити: `Ctrl+C`.

## Запуск у Kiro Crew на Mac

1. **Розпакуйте** архів у домашню папку, щоб вийшла папка `~/moi-hroshi`. Відкрийте Термінал і виконайте `cd ~/moi-hroshi`.
2. **Git.** Виконайте `git --version`. Якщо Mac запропонує встановити Command Line Tools, погодьтеся.
3. **Створіть локальний репозиторій:**
   ```
   git init -b main
   git add .
   git commit -m "Initial version"
   ```
4. **Встановіть Kiro CLI** за офіційною командою з документації Kiro:
   ```
   curl -fsSL https://cli.kiro.dev/install | bash
   ```
   Ця команда завантажує й запускає скрипт з інтернету. Якщо хочете, спершу відкрийте `https://cli.kiro.dev/install` у браузері й перегляньте його.
5. **Запустіть Crew:** `kiro-cli crew`, потім увійдіть в акаунт Kiro за підказками. Є також настільна програма Kiro Crew: https://github.com/kirodotdev/KiroCrew/releases.
6. **Відкрийте проєкт** (папку `~/moi-hroshi`) і почніть розмову з агентом **lead**. Агентів із `.kiro/agents/` має бути видно в списку агентів. Якщо їх немає: Customize → Agents → Create → вставте ім'я та вміст (після рядка `---` закриття шапки) із відповідного файлу.
7. **Вставте текст із `docs/TASK.md`** у розмову. Агент піде по етапах і зупинятиметься на ваше «так».

### Безпека під час роботи агентів
- Агенти можуть виконувати команди на вашому Mac. У налаштуваннях Crew (Settings → Security) задайте список заборонених команд: щонайменше `sudo`, `rm -rf`, `curl … | sh` (окрім початкової установки).
- `git push` та інші незворотні дії ролі мають робити лише після вашого прямого «так». Так прописано в завданні й у правилах ролей.
- Не показуйте агентам свої справжні суми, номери рахунків чи резервну копію. Тестуються лише вигадані дані.
- Кредити Kiro витрачаються на роботу агентів. Слідкуйте за витратою, особливо в перші дні.

## Публікація на GitHub Pages
1. Створіть на github.com **публічний** репозиторій (безкоштовний Pages працює з публічними). У ньому немає ваших даних, тому це безпечно.
2. У Терміналі (замініть `ВАШ_ЛОГІН` і `НАЗВА`):
   ```
   git remote add origin https://github.com/ВАШ_ЛОГІН/НАЗВА.git
   git push -u origin main
   ```
3. На GitHub: Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через хвилину-дві адреса буде `https://ВАШ_ЛОГІН.github.io/НАЗВА/`.

## Встановлення на телефон
- **iPhone (Safari):** відкрийте адресу → «Поділитися» → «На початковий екран».
- **Android (Chrome):** відкрийте адресу → меню ⋮ → «Встановити додаток» або «Додати на головний екран».

## Перенесення даних зі старого посилання
Дані зберігаються в браузері на конкретній адресі, тому на новій адресі додаток буде порожній.
1. У старому додатку: «Гроші» → «Резервна копія» → «Показати копію», скопіюйте весь текст у нотатки.
2. У новому: «Резервна копія», вставте текст, «Відновити з тексту».

## Важливо про збереження даних на iPhone
Safari на iPhone може очищати дані сайтів, якими не користувалися кілька днів, **якщо додаток не встановлений на головний екран** (актуальну поведінку перевіряйте в документації Apple). Тому:
- обов'язково додайте додаток на головний екран;
- час від часу робіть «Резервну копію» й зберігайте текст у нотатках.
Агент `dev` має додати нагадування про резервну копію прямо в додаток.

## Конфіденційність
Не додавайте в репозиторій жодних реальних даних і резервних копій. Файл `.gitignore` уже ігнорує типові назви, але остаточна відповідальність на вас: перед кожним `git push` дивіться `git status`.
